Parts from other projects
-------------------------
OpenIPC openhisilicon SDK headers
    dvrrec is compiled against these media API definitions.
    GPL-3.0. https://github.com/OpenIPC/openhisilicon

shine MP3 encoder (built into dvrrec)
    Fixed-point MP3 encoder, taken from the copy in OpenIPC Divinus, with two
    fixes of ours (third_party/shine/SOURCE.txt in the source code).
    GNU Library General Public License version 2 (LGPL-2.0.txt in this
    folder). Upstream: https://github.com/savonet/shine
    The complete source of dvrrec, including this modified shine, is in the
    repository above, so the program can be rebuilt with a changed shine.

Goke media libraries (dvr/lib/*.so)
    libgk_api.so, libsecurec.so, libupvqe.so, libdnvqe.so and
    libvoice_engine.so are the chip maker's binary libraries for the
    GK7205V200 family, taken unchanged from the OpenIPC firmware repository
    (package goke-osdrv-gk7205v200). They are not open source; OpenIPC
    redistributes them. https://github.com/OpenIPC/firmware

Rockchip techpoint TP9950 driver (Linux kernel, GPL-2.0)
    Reference for the TP2850 video decoder's setup sequence.
